# Survivre

Site d'information indépendant et non officiel pour se préparer, chez soi, à une crise longue : de 72 heures à 30 jours d'autonomie sans électricité, sans eau courante, sans réseau et sans commerces.

- Un seul fichier, `index.html`, sans installation ni serveur : il suffit de l'ouvrir dans un navigateur, et il fonctionne hors ligne.
- Un questionnaire calcule un plan personnalisé (eau, nourriture, énergie, gaz, toilettes de secours, budget) et une liste d'actions à cocher, palier par palier.
- Les réponses et les cases cochées restent dans le navigateur : rien n'est envoyé.
- Les repères sont tirés des doctrines officielles (SGDSN, Sécurité civile, guides nationaux européens) et de sources publiques citées en bas de page.

Les consignes des autorités priment toujours. En cas de danger immédiat : 112.

Version de novembre 2026.
